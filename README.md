# codesoft-m.l
# 🧠 Machine Learning Project Suite

This repository contains 5 individual machine learning projects, each solving a real-world problem using different datasets, techniques, and algorithms. The projects cover classification, fraud detection, natural language processing, and generative modeling.

---

## 📂 Projects Overview

### 🚀 TASK 1: Movie Genre Classification  
**Goal:** Predict the genre of a movie based on its plot summary.  
**Techniques:**  
- Text preprocessing, TF-IDF  
- Models: Naive Bayes, Logistic Regression, SVM  
**Libraries:** Scikit-learn, Pandas, NLTK  

---

### 💳 TASK 2: Credit Card Fraud Detection  
**Goal:** Classify credit card transactions as fraudulent or legitimate.  
**Techniques:**  
- Data preprocessing, feature scaling  
- Models: Logistic Regression, Decision Tree, Random Forest  
**Libraries:** Scikit-learn, Pandas, Matplotlib  
**Dataset:** [Click Here to Download](#)  
📁 Folder: `credit_card_fraud_detection/`

---

### 📉 TASK 3: Customer Churn Prediction  
**Goal:** Predict customer churn in a subscription-based service.  
**Techniques:**  
- Feature engineering (usage behavior, demographics)  
- Models: Logistic Regression, Random Forest, Gradient Boosting  
**Libraries:** Scikit-learn, Pandas, Seaborn  

---

### 📩 TASK 4: Spam SMS Detection  
**Goal:** Classify SMS messages as spam or legitimate.  
**Techniques:**  
- NLP with TF-IDF  
- Models: Naive Bayes, Logistic Regression, SVM  
**Libraries:** Scikit-learn, NLTK, Pandas  


---

### ✍️ TASK 5: Handwritten Text Generation  
**Goal:** Generate handwritten-like text using a character-level RNN.  
**Techniques:**  
- Recurrent Neural Networks (RNN)  
- Character-level modeling  
**Libraries:** TensorFlow/Keras, NumPy
